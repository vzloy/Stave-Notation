Temperature, Sampling, and the Measure Theory of LLM Agents

How prompt temperature, top-p, top-k, and other sampling parameters enter the cartesian double category as morphisms on probability measures — and what the notation says about controlling them
V. Nechyporuk-Zloy · 19 October 2026

1. The Problem: Every Agent Call Is a Random Variable

A deterministic tool — regionprops, a Gaussian blur, a file reader — is a function f: A → B. Given the same input, it returns the same output. In the cartesian double category Dbl(Img), it is a horizontal morphism with a trivial probability structure: a Dirac delta concentrated on one point.

An LLM agent is different. Given the same prompt, the same image, the same parameters, it can return different outputs on different runs. The σ-agent might choose Cellpose on one run and StarDist on another. The ε-agent might pass a segmentation on one run and flag it for re-examination on the next. This is not a bug — it is the fundamental nature of autoregressive token generation.

The question is: where does this randomness live in the notation, and how do the sampling parameters (temperature, top-p, top-k, frequency penalty, presence penalty) control it?

2. Autoregressive Generation as a Markov Chain

An LLM generates text token by token. At each step, it computes a probability distribution over the vocabulary V (typically 32k–128k tokens), conditioned on all previous tokens. This is a Markov chain on the token space:

-- Autoregressive generation -- At step t, the model computes: p(xₜ | x₁, x₂, ..., xₜ₋₁) = softmax(logits(x₁..xₜ₋₁) / τ) -- The full output probability is the product: P(x₁..xₙ) = ∏ₜ p(xₜ | x₁..xₜ₋₁) -- This is a Markov chain on V* (sequences over vocabulary V) -- with transition kernel K: V* × V → [0,1]

The key insight: the logits — the raw scores before softmax — are the model's deterministic output. Everything stochastic happens in the sampling step that converts logits to a chosen token. The sampling parameters control this conversion.

3. The Sampling Parameters

Temperature (τ)

Temperature scales the logits before softmax. It is a single real number τ ∈ (0, ∞) that controls the entropy of the output distribution.

p(xₜ) = softmax(logits / τ) τ → 0⁺ : distribution collapses to argmax (deterministic, greedy) τ = 1 : model's native distribution (calibrated probabilities) τ → ∞ : uniform distribution over vocabulary (maximum entropy)

Categorically, temperature is a morphism on the space of probability measures. Let Δ(V) be the probability simplex over the vocabulary. Temperature defines a family of endomorphisms:

Definition: Temperature as endomorphism

For each τ > 0, the temperature map T_τ: Δ(V) → Δ(V) sends a distribution p to the distribution T_τ(p) defined by T_τ(p)(x) ∝ p(x)^(1/τ). This is the power-mean reparametrisation of softmax. The family {T_τ} forms a one-parameter semigroup under composition: T_τ₁ ∘ T_τ₂ = T_{τ₁·τ₂}.

In the stave, temperature is a × parameter on the agent box — independent of the data, constant across runs:

σ: SegmentAgent(× Temperature=0.2, × Model=cyto3) -- Low temperature: agent almost always picks the same segmentation -- High temperature: agent explores diverse segmentation strategies

Top-p (nucleus sampling)

Top-p truncates the distribution to the smallest set of tokens whose cumulative probability exceeds a threshold p ∈ (0, 1], then renormalises. This is a truncation morphism on probability measures:

-- Sort tokens by probability descending -- Find smallest k such that Σᵢ₌₁ᵏ p(xᵢ) ≥ p_threshold -- Zero out all tokens beyond position k -- Renormalise Nucleus_p : Δ(V) → Δ(V) Nucleus_p(dist) = truncate(sort(dist), cumsum ≥ p) / Z

Top-p is not a continuous map on Δ(V) — small changes in the input distribution can cause the cutoff to jump, including or excluding a token at the boundary. This discontinuity has practical consequences: near the boundary, the agent's behaviour is sensitive to small prompt changes. The Lipschitz constant of Nucleus_p is unbounded near the cutoff.

Top-k

Top-k is simpler: keep the k highest-probability tokens, zero the rest, renormalise. This is a projection onto a subspace of Δ(V):

Definition: Top-k as projection

TopK_k: Δ(V) → Δ_k(V) projects from the full simplex to the k-face (the sub-simplex spanned by the k highest-probability vertices). This is an idempotent: TopK_k ∘ TopK_k = TopK_k. It is a retraction, with the inclusion ι: Δ_k(V) → Δ(V) as its section.

Frequency and presence penalties

These modify the logits based on what has already been generated. They are stateful — they depend on the generation history, not just the current token. In the Kleisli category, they are morphisms in the state monad:

-- Frequency penalty: subtract α·count(token) from logits -- Presence penalty: subtract β·1[token appeared] from logits FreqPenalty_α :: State TokenCounts (Logits -> Logits) PresencePenalty_β :: State TokenSet (Logits -> Logits) -- These are endomorphisms on the logit space that carry state -- State accumulates through the Markov chain

In the stave, frequency and presence penalties are also × parameters — but unlike temperature and top-p, they introduce a temporal dependency within the token generation. The agent's output distribution at token t depends on tokens 1 through t-1, not just through the autoregressive conditioning (which the model handles natively) but through the penalty's explicit modification of the logits. This breaks the "pure" Markov property — the penalty is an external intervention on the chain.

4. The Sampling Stack as a Morphism Chain

The full sampling pipeline — from raw logits to a chosen token — is itself a stave. Each sampling parameter is a morphism in a sequential composition:

-- The sampling sub-stave (internal to every agent box) Logits ── ℝ|V| ── ↓ ρ: FrequencyPenalty(× α=0.5) ← modify logits by history ↓ ρ: PresencePenalty(× β=0.3) ← modify logits by token set ↓ ρ: TemperatureScale(× τ=0.2) ← scale logits ↓ σ: TopK(× k=40) ← truncate to k tokens ↓ σ: NucleusSample(× p=0.95) ← truncate to nucleus ↓ ι: SampleToken ← draw from distribution ↓ Token ── V ──

Every agent box in the outer stave contains this inner sampling stave. The morphism types follow the same logic as image analysis: ρ transforms representations (logit modification), σ classifies and selects (truncation), ι acquires from a source (sampling from the distribution). The notation is self-hosting even inside the agent.

Order matters

Temperature before top-k is not the same as top-k before temperature. T_τ ∘ TopK_k ≠ TopK_k ∘ T_τ in general: temperature can change which tokens are in the top k. The stave's sequential composition (;) makes the order explicit. Most API implementations apply penalties first, then temperature, then top-k, then top-p, then sample — and the stave above shows that order. A different order is a different pipeline and may give different results.

5. Temperature in the Enriched Category

In the enriched category AgentV (§6 of the agentic image analysis document), the hom-objects are probability distributions over possible outputs. Temperature directly controls the shape of these hom-objects.

Temperature Hom-object shape Agent behaviour Image analysis effect
τ → 0 Dirac delta Deterministic: always picks argmax Always chooses the same model, same parameters. Reproducible but possibly stuck in a local optimum.
τ = 0.1–0.3 Narrow peak Near-deterministic with occasional variation Usually picks the best segmentation model but sometimes tries an alternative. Good for production pipelines where consistency matters.
τ = 0.5–0.8 Moderate spread Balanced exploration/exploitation Explores different approaches. Good for the meta-agent designing pipelines — considers unusual composite combinations.
τ = 1.0 Calibrated distribution Model's native uncertainty The model's own assessment of how likely each option is. Useful for uncertainty quantification — the distribution IS the uncertainty.
τ > 1.0 Flattened, high entropy Near-random exploration Tries everything, including bad ideas. Useful only for stress-testing or diversity sampling — never for production.

The enriched composition law says that composing two agents convolves their hom-object distributions. Temperature compounds: a pipeline of three agents at τ = 0.5 has more combined uncertainty than any single agent, because the convolution spreads the distribution at each step. This is why the Lipschitz budget matters — even moderate per-agent uncertainty can compound into high end-to-end uncertainty.

6. The Kleisli Arrow Formulation

Recall that each agent is a Kleisli arrow a → m b in the agent monad m = WriterT Provenance (StateT Context (ExceptT Failure (ReaderT Config IO))). The sampling parameters live in the ReaderT Config layer — they are read-only configuration, accessed via ×.

-- Config carries sampling parameters data SamplingConfig = SamplingConfig { temperature :: Double -- τ ∈ (0, ∞) , topP :: Double -- p ∈ (0, 1] , topK :: Int -- k ∈ {1, ..., |V|} , frequencyPenalty :: Double -- α ≥ 0 , presencePenalty :: Double -- β ≥ 0 , seed :: Maybe Int -- for reproducibility } -- Agent reads config via × σAgent :: Agent RawImage LabelImage σAgent img = do cfg <- asks samplingConfig -- read × parameters let sampler = mkSampler cfg -- build sampling chain model <- sampler (chooseModel img) -- stochastic choice params <- sampler (tuneParams img model) runSegmentation model params img

The seed parameter is categorically interesting. When set, it turns the Kleisli arrow back into an ordinary morphism — the randomness is fixed, so a → m b degenerates to a → b. This is the retraction from the Kleisli category back to the base category. In the stave, setting a seed is equivalent to collapsing the enriched hom-object back to a Dirac delta. The pipeline becomes reproducible.

7. The Prompt as Left Adjoint

The prompt — the system message, user message, and conversation history — is not a sampling parameter. It is categorically different: the prompt determines which distribution the model computes, while sampling parameters determine how we draw from that distribution.

Definition: Prompt as left adjoint

Let Prompt be the category of prompt texts and Dist be the category of distributions over output texts. The model defines a functor M: Prompt → Dist that maps each prompt to its output distribution. The sampling parameters define a functor S: Dist → Dist (endomorphism on distributions). The full agent call is S ∘ M: Prompt → Dist.

The prompt is a left adjoint in the sense that it is the most efficient way to change the output distribution: changing the prompt changes the logits everywhere simultaneously, while sampling parameters only reshape the existing distribution without adding information.

In the stave, the prompt is the content of the box — the morphism type (σ, μ, ε, ...) and its semantic role — while temperature and top-p are × parameters on the box. The distinction is visible: the box IS the prompt (what to do), the × IS the sampling configuration (how uncertain to be about it).

-- The box content IS the prompt -- The × parameters ARE the sampling config σ: "Segment this microscopy image. ← prompt (determines logits) Use Cellpose or StarDist as appropriate. Evaluate boundary quality." (× Temperature=0.2, ← sampling (shapes distribution) × TopP=0.95, × Seed=42)

8. Temperature and the Self-Correction Loop

Temperature interacts with the self-correction loop ({1..T}² pattern) in a precise way. The contraction theorem (§14 of the agentic document) says that convergence requires the correction map to be a contraction — λ < 1. Temperature affects the contraction rate:

  • Too low (τ → 0): the agent always makes the same choice. If the first choice is wrong, it cannot escape — the correction map is the identity, λ = 1. No convergence to a better solution.
  • Too high (τ > 1): the agent makes random choices. The correction map has high variance, possibly λ > 1. The segmentation quality oscillates rather than converging.
  • Optimal range (τ ≈ 0.1–0.5): the agent mostly exploits its best guess but occasionally explores alternatives. The correction map is a contraction with λ < 1. Quality improves monotonically toward the fixed point.
Proposition: Adaptive temperature schedule

The optimal strategy for the self-correction loop is an annealing schedule: start with higher temperature (τ ≈ 0.5–0.8) to explore the space of possible segmentations, then decrease temperature as quality improves (τ ≈ 0.1 at convergence). This is simulated annealing on the segmentation metric space. The cooling schedule ensures exploration early and exploitation late, with the contraction rate λ(τ) decreasing monotonically.

In the stave, the annealing schedule means temperature is not a fixed × parameter — it depends on the iteration index from {1..T}². It becomes an & input: temperature shares the iteration index with the quality score.

-- Annealing in the self-correction loop (Turns ── Params ──) & (Turns ── {1..T}² QualityΔ ──) & (Turns ── τ(t) ──) -- τ(t) = τ_max · exp(-αt) or τ(t) = τ_max / (1 + αt) -- Turn 1: τ = 0.7 (explore) -- Turn 2: τ = 0.4 (narrow) -- Turn 3: τ = 0.2 (exploit) -- Turn 4: τ = 0.1 (converge)

9. Different Agents, Different Temperatures

Not every agent should run at the same temperature. The optimal τ depends on the morphism type and its role in the pipeline:

Agent Recommended τ Rationale
ι-agent 0.0–0.1 File reading is nearly deterministic. The reader either works or doesn't. Minimal benefit from exploration.
φ-agent 0.1–0.3 Denoising parameters have a narrow optimal range. Some exploration helps (N2V vs median vs Gaussian), but the choice space is small.
σ-agent 0.2–0.5 Segmentation has the widest choice space (model, diameter, thresholds). Higher temperature lets the agent consider unconventional models. Self-correction loop with annealing.
μ-agent 0.1–0.2 Measurement selection is constrained by the biological question. Low uncertainty once the question is understood.
τ-agent 0.2–0.4 Tracking parameters (max displacement, gap closing) interact nonlinearly. Moderate exploration useful.
ε-agent 0.1 Quality judgement should be consistent. A quality gate that flips its verdict depending on the run is worse than useless.
ρ-agent 0.0–0.1 Format conversion is deterministic or near-deterministic. The conversion either works or it doesn't.
Meta-agent 0.5–0.8 Pipeline design benefits most from exploration. The meta-agent should consider unconventional composite combinations. This is where creativity matters.
The ε-agent paradox

The ε-agent evaluates quality — it must be consistent (low τ). But it is also the agent that detects whether the pipeline is stuck in a local optimum — which requires noticing that alternatives exist (higher τ would help). The resolution is that the ε-agent's judgement is low-temperature (is this segmentation good?), but its recommendation can be higher-temperature (what should we try instead?). These are two separate Kleisli arrows composed sequentially: ε_judge(× τ=0.1) ; ε_suggest(× τ=0.5).

10. Structured Output and Type Constraints

Modern LLM APIs offer structured output — constraining the model to emit valid JSON matching a schema. This is categorically a projection onto a sub-simplex: the vocabulary is partitioned into "valid next tokens" and "invalid next tokens" at each step, and invalid tokens are zeroed out before sampling.

-- Structured output as constrained sampling -- At each generation step: valid_tokens = grammar_mask(schema, generated_so_far) logits[~valid_tokens] = -∞ -- Then apply temperature, top-k, top-p, sample as usual

In the stave, structured output is the type row acting on the agent's internal sampling. The type row constrains the agent's output type (ℕ for labels, ℝ for intensities, {1..N}² for graph edges). When the agent uses structured output with a schema matching the type row, the type constraint is enforced at the token level — every generated token is consistent with the declared type. The type row becomes a sampling constraint.

Proposition: Type-constrained sampling preserves the Kleisli structure

Let C_S: Δ(V) → Δ(V_S) be the constraint morphism that projects onto the valid token sub-simplex for schema S. Then C_S ∘ T_τ = T_τ ∘ C_S — constraining and temperature-scaling commute (because temperature scales all logits uniformly, and -∞ stays at -∞ under any finite scaling). The Kleisli composition of constrained agents is still well-typed: if agent 1 outputs type A and agent 2 expects type A, the pipeline types check regardless of temperature.

11. The Measure-Theoretic View

Pulling everything together, the full picture is a measure-theoretic one. Each agent box in the stave is a Markov kernel — a measurable function from the input space to probability measures on the output space:

-- A Markov kernel (transition kernel, stochastic map) K :: Input -> Measure Output -- Composition of Markov kernels is the Chapman-Kolmogorov equation (K₂ ∘ K₁)(a, C) = ∫ K₂(b, C) dK₁(a, b) -- This IS Kleisli composition for the Giry monad -- The Giry monad G maps a measurable space X to G(X) = Measures(X) -- Kleisli arrows a → G(b) are exactly Markov kernels

The Giry monad is the "correct" monad for stochastic agents. It says that the space of probability measures on a measurable space is itself a measurable space, and Kleisli composition in the Giry monad is integration (the Chapman–Kolmogorov equation). This is exactly what happens when we compose two stochastic agents: the combined uncertainty is the integral of the second agent's uncertainty over all possible outputs of the first.

The sampling parameters — temperature, top-p, top-k — are natural transformations on the Giry monad. They modify the probability measure at each agent without changing the compositional structure. The stave's sequential composition (;) is still Kleisli composition in the Giry monad, regardless of what sampling parameters each agent uses.

12. Practical Implications for the Stave

What this means for notation and practice:

Sampling parameters are ×, not &

Temperature, top-p, top-k, and penalties are independent of the image data — they don't share an index with the data. They are × parameters. Exception: in the annealing schedule (§8), temperature depends on the iteration index, making it &.

The seed is a functor

Setting a seed on all agents defines a section of the forgetful functor U: Kleisli(Giry) → Set. It collapses the stochastic pipeline to a deterministic one. This is useful for reproducibility and debugging: run the pipeline with a fixed seed, inspect the output, then remove the seed for production.

Temperature compounds through composition

Three agents at τ = 0.3 compound into more uncertainty than one agent at τ = 0.3. The Lipschitz budget from the metric geometry section applies: L_pipeline ≤ ∏ L_agent, where each agent's Lipschitz constant increases with temperature. Keep critical-path agents (ε, ρ) at low temperature to control the budget.

Structured output + type row = token-level type safety

When the agent uses structured output matching the type row's schema, every token is type-consistent. The type row is no longer just a post-hoc check — it is a constraint on the sampling process itself. Type errors become impossible, not just detectable.

The meta-agent runs hottest

Pipeline design is where exploration matters most. The meta-agent should use the highest temperature in the system (τ ≈ 0.5–0.8) to consider unusual composite combinations. Once a pipeline is designed and validated, the execution agents run cool (τ ≈ 0.1–0.3) for consistency.

All sampling parameters are morphisms on probability measures — endomorphisms, projections, or truncations on the simplex Δ(V). They enter the stave as × parameters because they are independent of the image data. The Giry monad provides the Kleisli category in which stochastic agents compose. Temperature is the single most important parameter because it directly controls the entropy of each agent's hom-object in the enriched category — it is the dial between determinism and exploration.
